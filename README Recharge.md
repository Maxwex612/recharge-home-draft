# Recharge home page draft

A single-page draft of the Recharge website home page.

**To view it:** click `index.html`, then the download icon (or "Raw", then Save As). Double-click the saved file to open it in any browser. It needs an internet connection so the fonts load.

**What to know**
- This is a draft for review, not the final site.
- Links to other pages are placeholders. Clicking one shows a short "not in this draft" note.
- It works on desktop and phone widths.
